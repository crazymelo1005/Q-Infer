# ADR-001：采用三层分层存储与专家缓存，而非权重全量常驻

**状态**：Accepted
**日期**：2026-10-09

---

## 背景

主案例模型 Qwen3.8-Flash-Next 有 125B 主参数加 51B 外挂记忆表（FP8 检查点 172.78 GiB，BF16 335.28 GiB）。目标形态是单卡 RTX 5060 Ti 16 GB。

服务端派引擎（vLLM、SGLang、NInfer）的全部调度优化都建立在权重常驻显存的前提上。该前提在本硬件上不成立，且随下一代目标（5 至 10 万亿参数）也不会成立。

## 决策

引擎以权重永远装不进显存为第一性假设，采用三层分层存储：

| 层 | 内容 |
|----|------|
| 显存 | 每 token 必用的稠密部分（注意力、门控残差、路由器、共享专家、输出头、MTP 层、KV 热窗），剩余显存全部作为专家缓存 |
| 主机 pinned 内存 | 全部 24,576 个专家；记忆表中频行 |
| NVMe | 记忆表长尾行、冷专家 |

## 备选方案

1. 权重全量常驻并增加显存（服务端路线）。否决：16 GB 是硬边界，且不可扩展。
2. 层级卸载，逐层把权重经 PCIe 搬回显存。否决：每层都在等搬运，而 PCIe 5.0 x8 每卡约 31.5 GB/s，低于内存带宽。
3. 专家级卸载加就地计算。采纳。

## 后果

正面：

- 在 16 GB 上可运行 125B 级模型。
- 显存增加直接转化为命中率提升，约每 GB 容纳 700 个专家，收益连续可预期。
- 与超稀疏 MoE 的演进方向一致。

负面：

- 引入三层管理的复杂度：页表、预热、驱逐、预取。
- 性能对命中率高度敏感。参考引擎在环境2 双卡期的实测命中率为 0.935 至 0.975（专家槽位 11,967，占用 16,416 MiB），工作集切换时会波动。
- CPU 侧算力成为新的潜在上限，本平台无 AVX-512 与 AMX。

主机内存余量紧张是本决策最大的外部风险，见 [risks.md](../risks.md) 的 R-07 与 [gates.md](../gates.md) 的 G-11。
