编号 `R-NN` 只增不改。每条记录影响、概率、依据、对策与关联门禁。风险指尚未确定的事；已经实测确认的负结果单列在第 2 节，不得重新当作可争取的收益。

## 2. 已确认的负结果

以下为实测或官方口径确认的事实，不得作为可争取的收益重新讨论。出处见 [`../research/references.md`](../research/references.md) 的 S-01、S-02、S-25、S-26。

| 事实 | 条件 |
|------|------|
| 文件层预取的暂存变体在内存余量紧张时为负收益，余量充足时为正收益 | 上游在两种内存上限下的对照实验 |
| 核显参与的预取变体在共享内存总线平台上为负收益 | 该平台内存压力下伴随 GPU 复位 |
| 命中率与解码速度不保证同向 | 上游定义中命中率不含经 PCIe 搬入的专家 |
| 表行异步预取并非空白 | 上游推理引擎与模型官方配方均已实现 |
| 专家侧跨层预测预取与批量 IO 并非空白 | 上游引擎已实现，且验证逐位输出不变 |
| 启动自动标定并非空白 | 上游引擎已有对应开关 |
| 索引器 KV 独立精度并非空白 | 上游推理引擎有独立旋钮，同类项目已在同型号 16 GB 卡上使用 |
| 层间预取与传输计算重叠在 KV 侧并非空白 | 同类项目将其作为对照基线 |
| 表行访问在去重后既无顺序性也无近邻复用 | 语料为参考引擎仓库的文档与源码（4K / 32K / 262K token）与 48 条独立请求；离线重放，哈希经其 oracle 向量逐位校验。相邻同页率与去重后同页率均为 0（16 个头把表切成 16 个互不相邻区间，结构性为零）；行级重复率 0.28 至 0.59，但复用距离中位数达上万次请求，16 请求窗口内仅 0.14% |

## 3. 维护规则

- 门禁不通过时，把负结果写入本节并标注条件，不得删除对应条目。
- 风险若已实际发生，移入第 2 节并记录观测数据。
- 新增风险即分配下一个 `R-NN`，并在本表登记。
