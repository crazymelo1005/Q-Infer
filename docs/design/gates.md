# 门禁与待测项

本文登记设计中所有必须先测量的假设。编号 `G-NN` 只增不改；实测结果回填到本表的记录列，同时写入 [`research/`](../research/) 的对应条目。

门禁指测量不通过就必须砍掉对应子系统并记录负结果的假设。当前六条门禁：G-04、G-07、G-08、G-09、G-10、G-11。其余为一般待测项，影响参数取值，不直接决定子系统去留。

## 2. 共用测量约定

- 分母口径：同机、同量化档、同任务集、同并发。分母必须是环境2 上的实测。
- 平台必须写明：环境1（并区分 WSL 内还是 Windows 宿主）或环境2。三套口径不可混用；涉及内存容量、内存带宽、PCIe 带宽的项尤其如此。
- 单卡硬下限的验收在环境2 上以仅启用一张卡的方式进行；环境1 的 WSL 因内存上限与缺少 KV 流式能力，不作为相对参考引擎提速的对照平台。
- 每次配置重复不少于 5 次，报中位数与区间，并记录机器画像。
- 投机与预取类测量必须使用真实任务集，禁用随机 prompt。
- 冷启动与稳态分开记录。引擎的累计窗口随进程重启归零，历史值无法从端点复现。
- 负结果必须写入 [`risks.md`](risks.md) 与 [`research/`](../research/)，不得删除或静默保留。

## 3. 已知的上游对照值

以下数值用于判断本项目测量结果是否合理，不作为验收基线。

| 项 | 上游实测 | 条件 |
|----|---------|------|
| 文件层预取的暂存变体 | 内存余量紧张时 −32.6%，余量充足时 +25.7% | 同一机制在不同内存上限下的对照，结论翻号 |
| 核显参与的预取变体（共享内存总线平台） | −19% | 该平台在内存压力下伴随 GPU 复位 |
| 命中率与解码速度的关系 | 不保证同向 | 该引擎的命中率不含经 PCIe 搬入的专家 |

最后一条意味着命中率不能作为优化目标，只能作为观测量，且引用时必须同时给出 PCIe 侧占比与空闲显存。
